# The daemons still carrying vanilla's name

**146 of them, in 88 families.** Every one of Kanto's 151 is already ours — what is left is **Johto and Hoenn**,
and all of them are currently **unreachable**, which is why T-40 stopped where it did.

The chain is **naming → Index entry → OPUS margin**, and 2.10's rule is that naming a daemon brings its
learnset into scope. So a name is never just a name here: it is the first of four jobs.

The **type** column is the constraint. A name has to answer the type it already has — that is what makes
this hard, and also the only foothold there is.
