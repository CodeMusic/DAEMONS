# Speech to text (moved)

The MLX Whisper server the companion hears through (companion C-83) moved to the companion on 2026-11-11 (C-340): it is
`seer/stt/whisper_server.py` in [daemons-companion's local cloud](https://github.com/CodeMusic/daemons-companion/tree/main/seer), installed on port 8770 by `seer/bindSeer.sh`
when local models are chosen. With a Tiiny, the Tiiny hears instead.
